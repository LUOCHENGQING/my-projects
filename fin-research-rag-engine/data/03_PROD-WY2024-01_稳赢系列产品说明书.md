# 稳赢系列 90 天持有期债券型产品说明书

## 一、产品概况

本产品为债券型资产管理产品，管理人为示例基金管理有限公司，托管人为示例银行股份有限公司。产品代码 WY2024-01，风险等级 R2（中低风险）。

| 要素 | 内容 |
| --- | --- |
| 产品代码 | WY2024-01 |
| 产品名称 | 稳赢系列 90 天持有期 |
| 风险等级 | R2（中低风险） |
| 产品类型 | 债券型 |
| 最短持有期 | 90 天 |
| 起投金额 | 1 万元 |
| 追加投资 | 1000 元起 |
| 业绩比较基准 | 3.20%（年化） |
| 管理费率 | 0.30% / 年 |
| 托管费率 | 0.02% / 年 |
| 销售服务费率 | 0.10% / 年 |
| 申购费率 | 0% |
| 赎回费率 | 持有满 90 天为 0%，未满 90 天为 0.50% |
| 赎回确认 | T+1 个工作日 |
| 资金到账 | T+2 个工作日 |

## 二、投资范围与比例

本产品主要投资于国债、政策性金融债、地方政府债、企业债、公司债、中期票据、短期融资券、同业存单与银行存款。

| 资产类别 | 投资比例下限 | 投资比例上限 |
| --- | --- | --- |
| 债券 | 80% | 100% |
| 现金及货币市场工具 | 0% | 20% |
| 权益类资产 | 0% | 5% |
| 可转换债券 | 0% | 10% |

本产品不投资于股票二级市场，不投资于衍生品，不进行正回购放大操作。

## 三、集中度与杠杆约定

本产品投资于同一资产的资金不超过产品净资产的 15%。产品总资产不超过产品净资产的 100%，即不设杠杆。

## 四、流动性安排

投资者持有份额满 90 天后，可在每个开放日提出赎回申请。持有期未满 90 天提出赎回的，需承担 0.50% 的赎回费。

产品设单日赎回上限：单个开放日净赎回比例超过产品总份额 10% 时，管理人有权启动**延期办理**机制。

## 五、风险揭示

本产品风险等级为 R2，适合风险承受能力为 C2（稳健型）及以上的投资者。投资者应注意以下风险：

- 市场风险：债券价格随市场利率波动，产品净值可能出现回撤。历史测算显示，在利率上行 100 个基点的情景下，产品净值最大回撤约为 1.8%。
- 流动性风险：持有期未满 90 天赎回需支付赎回费。
- 信用风险：持仓债券的发行人可能发生违约。
- 业绩比较基准不代表实际收益，不构成收益承诺。

## 六、费用与收益分配

本产品不收取业绩报酬。收益分配采用**每日计提、按月结转份额**的方式。

管理费、托管费与销售服务费按前一日产品净值计提，合计 0.42% / 年。

## 七、申购与赎回规则

| 操作 | 确认时点 | 份额确认 | 备注 |
| --- | --- | --- | --- |
| 申购 | T 日 15:00 前 | T+1 个工作日 | T 日净值 |
| 赎回 | T 日 15:00 前 | T+1 个工作日 | 需满足持有期 |
| 分红方式变更 | T 日 15:00 前 | T+1 个工作日 | 红利再投资 / 现金分红 |

## 八、适当性提示

销售机构应当确认投资者风险承受能力等级不低于 C2。对**年满六十五周岁**的投资者，本公司要求销售机构执行双人见证程序。

本产品不适合将资金全部集中于单一产品的投资者，建议单一产品配置比例不超过投资者可投资资产的 30%。
